
## 機能要件

### 1. 地図表示

- システムは地図を画面上に表示する
- ユーザーは地図をクリックまたはタップできる
- 初期表示時は中心地点、マーカー、円は未設定とする

### 2. 中心地点の指定

- ユーザーは地図上の任意地点をクリックまたはタップして中心地点を指定できる
- ユーザーは地名検索により候補地点を検索し、選択した地点を中心地点に指定できる
- ユーザーは現在地ボタンをタップして、デバイスの位置情報を中心地点として指定できる
- 中心地点は常に1件のみ保持する
- 新しい中心地点が指定された場合、既存の中心地点は置き換える

### 3. 地名検索

- ユーザーは検索ボックスに地点名を入力できる
- システムは入力文字列の変更をリアルタイムに検知し、候補地点を表示する（インクリメンタルサーチ）
- ユーザーは候補地点を1件選択できる
- 候補地点選択時、地図は対象地点へ移動する（ズームレベルは維持する）
- 候補地点選択時、検索ボックスには選択した地点名を表示する
- 同名地点が複数存在する場合、候補一覧から選択できる
- API通信エラー時はエラーメッセージを表示する

### 4. 距離入力

- ユーザーは半径距離を km 単位で入力できる
- 小数入力を許可する
- ユーザーは▲▼ボタンで 0.1 km 単位の増減ができる
- ユーザーはスライダーで 0.1〜50 km の範囲を直感的に変更できる（スライダーの最大値は 50 km。50 km 超は入力欄で直接入力する）
- 距離入力値が有効な場合、システムは半径として保持する
- 距離入力値が無効な場合、システムはエラー表示を行う

### 5. 現在地ボタン

- 地図右下に現在地ボタンを表示する
- ユーザーはボタンをタップして、デバイスの位置情報を中心地点として設定できる
- 位置情報取得中はスピナーを表示し、ボタンを無効化する
- 位置情報取得後、地図は取得した地点へ移動し、ズームレベルを 12 に設定する
- 位置情報の取得に失敗した場合、ボタン付近にエラーメッセージを表示する
- ブラウザが Geolocation API に非対応の場合、ボタンを無効化する

### 6. 円表示

- システムは中心地点と半径距離が有効な場合のみ円を表示する
- 円は常に1件のみ表示する
- 中心地点が変更された場合、円は新しい地点に合わせて更新する
- 距離が変更された場合、円の半径を更新する

### 7. マーカー表示

- システムは中心地点にマーカーを表示する
- マーカーは常に1件のみ表示する
- 中心地点変更時、既存マーカーは新しい地点に更新する

### 8. 情報表示

- システムは現在の中心地点の緯度経度を表示する
- システムは現在の半径距離を表示する
- 緯度経度は小数点以下6桁表示とする

### 9. クリア

- ユーザーはクリア操作を実行できる
- クリア実行時、以下を初期状態へ戻す
    - 中心地点、マーカー、円
    - 座標表示、エラー表示
    - 検索入力欄、距離入力欄
    - 地図の表示位置（初期位置: 東京中心）
