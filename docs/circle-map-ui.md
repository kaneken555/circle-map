## 画面構成

### 領域一覧

| 領域 | 内容 |
|---|---|
| ヘッダー領域 | アプリ名・説明文 |
| 操作パネル領域 | 地点検索ボックス、検索候補一覧、距離入力欄、ステッパーボタン（▲▼）、kmラベル、スライダー、クリアボタン、エラーメッセージ表示領域 |
| 地図領域 | 地図本体、中心地点マーカー、半径円、現在地ボタン（右下フローティング） |
| 情報表示領域 | 緯度、経度、半径 |

---

### PCレイアウト（横幅 768px 以上）

```
┌─────────────────────────────────────────┐
│              ヘッダー領域                │
├──────────────┬──────────────────────────┤
│              │                          │
│  操作パネル  │       地図領域           │
│  領域        │                          │
│              │                          │
│  情報表示    │                          │
│  領域        │                          │
│              │                          │
└──────────────┴──────────────────────────┘
```

- 操作パネルと地図を横並びに配置する（左サイドバー構成）
- 操作パネル・情報表示領域は左カラム内で縦に並べる
- 地図領域は残りの幅をすべて使用する
- 地図の高さはビューポートの高さいっぱいに表示する

---

### スマホレイアウト（横幅 767px 以下）

```
┌─────────────────────┐
│    ヘッダー領域      │
├─────────────────────┤
│                     │
│     地図領域         │  ← 画面の約50%の高さ
│                     │
├─────────────────────┤
│   操作パネル領域     │  ↑
│   情報表示領域       │  スクロール可能
└─────────────────────┘
```

- 地図を上部に大きく表示し、操作パネル・情報表示を下部に配置する
- 地図の高さはビューポートの約50%とする
- 操作パネル・情報表示領域は縦スクロール可能にする
- 検索候補一覧はソフトキーボードと重ならないよう、入力欄の直下に表示する

---

### 各領域の詳細

#### ヘッダー領域

- アプリ名
- 簡単な説明（例: 「地図上で中心地点を選び、指定距離の円を表示します」）

#### 操作パネル領域

- 地点検索ボックス
- 検索候補一覧（入力欄の直下に表示）
- 距離入力欄 + ステッパーボタン（▲▼）+ km ラベル（横並び）
- 半径スライダー（0.1〜50 km）
- クリアボタン
- エラーメッセージ表示領域

#### 地図領域

- 地図本体
- 中心地点マーカー
- 半径円
- 現在地ボタン（右下フローティング、44×44px）

#### 情報表示領域

- 緯度・経度・半径を縦に並べて表示
